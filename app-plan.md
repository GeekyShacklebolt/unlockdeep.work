# Ritual — App Plan

## Color Palette

Extracted from the landing page v1 design. Use these consistently across the Android app.

### Primary — Amber

| Name | Hex | Usage |
|------|-----|-------|
| Amber 600 | `#d97706` | Primary CTA, buttons, accent borders, links |
| Amber 700 | `#b45309` | Button hover, section labels, hints |
| Amber 400 | `#fbbf24` | Highlight/emphasis text on dark backgrounds, comparison card border |
| Amber 100 | `#fef3c7` | Soft backgrounds (outcome box, icon bg, footer), glow accents |
| Amber 50 | `#fffbeb` | Highlighted card backgrounds |

### Neutrals — Stone (warm grays)

| Name | Hex | Usage |
|------|-----|-------|
| Stone 900 | `#1c1917` | Primary text, dark section backgrounds (hero, insight, philosophy) |
| Stone 700 | `#44403c` | Body text, secondary content |
| Stone 600 | `#57534e` | Subtitles, secondary descriptions |
| Stone 500 | `#78716c` | Muted text, card body copy |
| Stone 400 | `#a8a29e` | Labels, timestamps, disabled text |
| Stone 300 | `#d6d3d1` | Arrows, muted borders, inactive dots |
| Stone 200 | `#e7e5e4` | Card borders, dividers |
| Stone 100 | `#f5f5f4` | Alternate section background |
| Stone 50 | `#fafaf9` | Page background, primary section background |

### Special

| Name | Hex | Usage |
|------|-----|-------|
| White | `#ffffff` | Card backgrounds, text on dark |
| Cream | `#f0e4d4` | Hero title text (Playfair Display serif) |
| Mint gradient | `#ecfdf5` | Outcome box gradient end (paired with Amber 100) |

### Dark Mode Text Opacity

Used for text on `#1c1917` backgrounds:

| Opacity | Usage |
|---------|-------|
| `rgba(255,255,255, 0.85)` | Primary text on dark |
| `rgba(255,255,255, 0.6)` | Secondary text on dark |
| `rgba(255,255,255, 0.5)` | Muted text, stat descriptions |

### Typography

| Font | Weight | Usage |
|------|--------|-------|
| Playfair Display | 700, 800 | Hero title "Ritual" (serif, editorial feel) |
| Inter | 400, 500, 600, 700, 800 | Everything else (clean, modern sans-serif) |

### Design Principles

- **Warm, not cold** — Stone neutrals instead of pure grays. Amber instead of blue.
- **Minimal stimulation** — No animations, no gamification visuals. Deliberately boring UI during sessions.
- **High contrast on dark** — Dark sections use `#1c1917` with warm white text, amber accents.
- **Consistent accent** — Amber is the only accent color. No secondary color needed.
